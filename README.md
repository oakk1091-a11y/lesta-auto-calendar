# Lesta Auto Calendar 🎯

Скрипт для автоматического ежедневного сбора наград табеля-календаря в игре «Мир танков» (Lesta Games).

Работает локально через сохранённый профиль — ваши логины и пароли никуда не передаются и остаются только у вас на компьютере.

---

### Требования
* **Python 3.10+** (при установке обязательно поставьте галочку **Add Python to PATH**).

* Умение читать и понимать всё что будет сказано.

### Установка и настройка

1. Нажмите зелёную кнопку **Code** вверху этой страницы и выберите **Download ZIP**.
2. **ОБЯЗАТЕЛЬНО распакуйте ZIP-архив** в обычную папку (например, на диск `C:\` или на Рабочий стол). Запускать прямо из архива нельзя!
3. Откройте командную строку (**cmd**) и установите Playwright:
   ```bash
   pip install playwright
   ```
4. Скачайте браузер для работы скрипта командой:
   ```bash 
   playwright install firefox
   ```
5. Запустите скрипт через файл `run.bat` (или `python lesta_bot.py`), чтобы открылся браузер.
6. Войдите в свой аккаунт на сайте «Мира танков» и обязательно поставьте галочку **«Запомнить меня»**.
7. Закройте браузер — сессия сохранится в локальную папку профиля.
8. Откройте файл `lesta_bot.py` через Блокнот, найдите строку `headless=False` и замените её на `headless=True`, после чего сохраните файл (**Ctrl + S**). Теперь скрипт будет работать без открытия лишних окон.

    ###  ⏰ Автоматический запуск каждый день (Windows)

Чтобы скрипт сам забирал награду каждый день и не пропускал её, даже если компьютер включается в разное время:

1. Нажмите сочетание клавиш **Win + R**, введите `taskschd.msc` и нажмите **Enter** (откроется «Планировщик задач»).
2. В правой колонке нажмите **«Создать задачу...»** (Create Task) — именно обычную задачу, не простую!
3. Во вкладке **«Общие»** (General):
   * В поле «Имя» напишите: `Lesta Daily Claim`.
   * Поставьте галочку **«Выполнять с наивысшими правами»** (Run with highest privileges).
4. Во вкладке **«Триггеры»** (Triggers) нажимаем **«Создать...»**:
   * **Триггер 1 (По расписанию):** Выберите «Ежедневно», укажите удобное время (например, `12:00`) и нажмите **ОК**.
   * **Триггер 2 (При включении/входе):** Снова нажмите «Создать...», в верхнем выпадающем списке выберите **«При входе в систему»** (At log on) и нажмите **ОК**.
   *(Благодаря второму триггеру, если в 12:00 комп был выключен, скрипт заберёт награду сразу, как только вы сядете за ПК!)*
5. Во вкладке **«Действия»** (Actions) нажмите **«Создать...»**:
   * Действие: «Запуск программы».
   * В поле **«Программа или сценарий»** напишите `wscript.exe`
   * В поле **«Добавить аргументы»** обязательно вставьте полный путь к `.vbs` файлу (нажмите правой кнопкой мыши по `.vbs` файлу и нажмите **копировать как путь**), с кавычками.
   * В поле **«Рабочая папка (Start in)»** обязательно вставьте полный путь к папке с проектом (например: `C:\lesta-auto-calendar`), **без кавычек**.
   * Нажмите **ОК**.
6. Во вкладке **«Параметры»** (Settings):
   * Поставьте галочку **«Немедленно запускать задачу, если пропущен плановый запуск»**.
   * Нажмите **ОК** для сохранения задачи.

Всё! Теперь запуск настроен намертво: скрипт тихо отработает в фоне либо по времени, либо сразу при включении компа.
